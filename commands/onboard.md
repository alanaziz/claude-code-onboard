description: "Set up your AI workspace with a 10-minute guided onboarding"
---

Use the `claude-code-onboard:onboard` skill to run the full onboarding flow.

Check `~/Desktop/` for existing `OS-*` folders. If any exist, list them and ask whether this is a new workspace (a new brand/venture) or an update to one of the existing ones — if it's an update, suggest `/update-context` instead, since running `/onboard` again against an existing `OS-[Name]` folder overwrites its context files.
